Model zoo

Each model loads already trained, with notes on what to look for. The training history is kept, so you can scrub back and watch it learn.

How to read the network

Columns are layers, squares are neurons and curves are weighted connections. Signals flow left to right; error signals flow right to left during training.

Colour

Blue is positive and orange is negative everywhere: weights, activations, signals and the two classes of a binary problem. Violet measures gradients, the pressure to change.

The probe

One input is always being traced through the network. Hover over the Output map to move it, click to pin it, or click a data point to use that example. The Neuron tab shows its arithmetic.

Maps

With Maps on, each neuron shows what it outputs for every possible input, so you can watch simple shapes in the first layer combine into complex ones deeper in.

Building the network

Use − and + under a layer to change its size, the + between layers or the Hidden layers control to add depth, and the chip under each layer to pick its activation function. To give one neuron its own function, select it and use the Neuron tab. The chip under Output picks the loss function.

Validation and test data

Training uses one part of the data. A second part, the validation set, is scored as it trains to show how well it generalizes. A third, the held-out test set, is only scored when you press Run test, once you have finished tuning.

Zoom

Pinch, double-tap or Ctrl + scroll on the network, the output map or the hidden space to zoom into that part; drag to pan. Labels stay readable and show full formulas once there is room.

Install as an app

On an iPhone or iPad, open this site in Safari, tap Share, then Add to Home Screen. On Android, open the browser menu and tap Install app. On a computer, use the install button in the address bar. The app opens full-screen and keeps working offline.
